# Musk × Huang 智囊团

[English](README.md) | **简体中文**

一个给 Claude 用的技能（Agent Skill）。装上之后，你可以就人生、职业、学习、创业这类问题，请教 Elon Musk 和黄仁勋（Jensen Huang）在公开场合讲过的看法。

每个观点都带原视频的链接和时间戳，点开就能核对。

> 这是第三方整理，和两人及其公司没有任何关系，也没有得到他们的认可。内容是转述，不是原话。

## 它能做什么

- 回答"他们怎么看这件事"，并给出处。
- 指出两人在哪里看法不同，以及他们自己前后改过的说法。
- 讲他们自己承认的代价，和普通人不该照搬的地方。
- 把"他们说的"和"助手自己的建议"分开写。

## 它不做什么

- 不用第一人称扮演这两个人，不替他们编话。
- 不评股票，不给投资建议。
- 不回答产品参数、公司新闻和政治立场。这些不在索引里。

## 可以这样问

- 我想辞职创业，但有点怕，他们会怎么说？
- AI 发展这么快，我现在学编程还有意义吗？
- 我同时在做好几件事，都不想放，怎么办？
- 给我开个圆桌：读博值不值得。
- 马斯克说几年内工作会变成可选，可信吗？

用什么语言问，它就用什么语言答。技能说明是英文写的，索引里每一条都有英文和中文两种转述。

## 安装

### Claude Code

把仓库克隆到个人技能目录：

```bash
git clone https://github.com/razer-chan/musk-huang-council ~/.claude/skills/musk-huang-council
```

装好后直接提问即可。如果当前会话里技能没有出现，运行 `/reload-skills`。

### Claude 应用（网页版和桌面版）

1. 在本仓库的 Releases 页面下载 `musk-huang-council.zip`。
2. 打开 Claude，进入 Customize → Skills，点 +，选择 Create skill → Upload a skill，上传这个 zip。
3. 把技能开关打开。

需要在设置里启用代码执行和文件创建。菜单位置以 Claude 官方帮助为准。

## 里面有什么

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 技能本体：什么时候用、怎么回答、几条底线 |
| `references/index.md` | 180 条观点索引，分 15 个主题，英文和中文对照 |
| `references/tensions.md` | 两人的分歧、改过的看法、代价、不该照搬的地方 |
| `references/principles.md` | 十条贯穿两人的原则 |
| `references/method.md` | 索引是怎么整理的，可靠到什么程度 |

十五个主题：选方向、怎么想问题、犯错与反馈、怎么学习、教育与上大学、工作强度与代价、韧性与挫折、冒险与创业、优先级、AI 与未来的工作、做事方法、团队与用人、钱、意义与乐观、怎么看他们的预测。

## 可靠到什么程度

- 原料是两人 1998 年到 2026 年的 1,056 份公开视频文字稿，约 718 万词。
- 索引里每一条，都由脚本回到文字稿里确认过那句话存在。
- 说话人是谁、转述准不准，靠阅读判断，可能有错。
- 55% 的文字稿没有被读过，主要是发布会、财报会和政治集会。

细节见 [`references/method.md`](references/method.md)（英文）。
